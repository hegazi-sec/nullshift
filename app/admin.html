VirusTotal (Threat Intelligence)
When set, NullShift automatically enriches IPs, domains, and file hashes found in each investigation against VirusTotal — regardless of RAG status. Private IPs and filename look-alikes are skipped, and lookups are capped at 4 per message to respect the public API rate limit. Verdicts are attached to the evidence bundle the analyst LLM reasons over.
VirusTotal v3 API key. Test key checks the key in the field, or the saved key when the field is empty.
Webhook Alert Ingestion
Lets your SIEM push alerts directly into the NullShift alert inbox. Point the SIEM webhook at POST /api/alerts/ingest with the shared token in the X-Webhook-Token header. Ingestion stays disabled until a token is set.
At least 24 characters recommended. Generate token makes a random one.
Example: curl -X POST https://your-host/api/alerts/ingest?source=wazuh -H "X-Webhook-Token: <token>" -H "Content-Type: application/json" -d @alert.json
Alert severity
NullShift reads each SIEM's own severity field and maps it onto low, medium, high and critical. A rule override wins over everything; an alert whose shape isn't recognised is read on the primary SIEM's scale. Saving re-scores every alert already in the inbox, which also changes what the Triage agent's auto-dismiss limit applies to.
